# rgaa-assist

An audit assistant for RGAA. It examines a sample of web pages in a real browser, decides what a machine can decide, and prepares the rest for a human reviewer. It never declares conformance.

**Status:** specification approved on 2026-11-15 (draft 0.4). Milestone M1 started on 2026-11-16: the candidate coverage map, the schemas and the ruleset contract. Nothing is enabled and nothing audits a page yet.
